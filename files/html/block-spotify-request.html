Enter the Discord's console on the discord PC APP by pressing CTRL+SHIFT+I and open the "Console" tab.

Type "allopasting" (or equivalent, see the console to be sure)

Paste this in the Console :

XMLHttpRequest.prototype.realOpen = XMLHttpRequest.prototype.open;
var myOpen = function(method, url, async, user, password) {
  if (url == "https://api.spotify.com/v1/me/player/pause") {
    url = "https://api.spotify.com/v1/me/player/play";
  }
  this.realOpen (method, url, async, user, password);
}
XMLHttpRequest.prototype.open = myOpen;

And now, Spotify won't pause when you play music AND when you're in discord call at the same time

After Closing Discord, you have to re-paste this in the console (CTR+SHIFT+I) after Restarting Discord. You don't have to retype "allowpasting" all the time. Just after Discord (re)installation.
